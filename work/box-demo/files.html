03 / THE POINT

不是让模型更听话。
是给执行过程一个边界。

如果你的产品允许 agent 写文件、装依赖、运行代码，你就需要决定：它获得什么环境，能影响谁，用完如何回收。

  • 模型决定要执行什么任务。
  • 你的产品决定任务被允许使用什么资源。
  • BoxLite提供可通过 API 管理的独立 microVM。
普通云服务器或容器不能做吗？

也可以。普通虚拟机可以提供独立内核；经过正确配置的权限和容器也能提供不同程度的隔离。本实验的共享对照组故意不设置每任务文件权限。BoxLite 的价值是把独立执行环境的创建、运行和生命周期管理做成 SDK/API，而不是证明其他方案一律不安全。
